> **本文件是六系职业与数值体系的唯一事实源。** V0.1~V0.4 已移入 `docs/archive/`，仅作历史追溯，**不再作为依据**。

> 计算模型：`Tools/Numerics/class_balance_model.py`（局内）、`Tools/Numerics/meta_model.py`（局外），均可复现。

## 1. 设计目的

1. 让 6 个角色在「同框架不同体验」下成立：共用一套战斗底座、升级卡池与超武规则，每系有**不可替代的核心机制**，避免"换个模型的数值差异"。
2. 差异化落在**可感知层**（开局 30 秒能感觉到）：每系 = 一个专属机制 + 一组属性基线 + 一条硬性限制 + 一组卡池权重 + 一个显性代价。
3. 与 USP 三支柱对齐：① 低操作门槛自动割草不被职业差异破坏；② 超武进化链按系别分化；③ 图鉴/收集以「六系 × 收集度」驱动长线。
4. 全部差异进入 Luban 表，代码零硬编码。
5. **局内策略优先**：强度预算 局内 75% / 局外 25%（对标 Brotato 验证结论）。

## 2. 名词解释

| 术语 | 定义 |
|---|---|
| 境界 Realm | 局外核心成长线，9 大境界 × 4 小阶 = 36 阶，提供属性基线并解锁法宝槽/卡池/天赋点 |
| 法宝 Treasure | 局外装备，4 槽位（本命/护身/遁光/灵辅），6 品阶（法器→道器），每品阶携带 1~6 条词条 |
| 词条 Affix | 法宝携带的属性或功能条目，数值可洗炼（重铸），是法宝系统的可玩性来源 |
| 天赋树 TalentTree | 局外三分支（杀伐/长生/机缘），提供效率与机制，不提供能力解锁 |
| 修为 Cultivation | 突破境界的资源，由单局结算（存活时间/击杀/Boss 进度）折算 |
| 打坐 Cultivate | 局外挂机修炼态：在线每 10 秒结算一次修为进度，**离线即停**（与框架 §3.7 删除的 16h AFK 巡逻挂机性质不同：那个是离线自动产出，本项是主动在线挂机） |
| 渡劫 Tribulation | 修为进度满后主动触发的突破判定；成功升下一境界，失败降一定进度不重置 |
| 转盘钥匙 RouletteKey | 局内开宝箱时记录获得，局外用于幸运转盘；**每次固定消耗 1 把**，与倍率无关 |
| 天机倍率 Multiplier | 转盘的**第二维度**，独立抽取 ×1/×2/×3/×5/×10；最终奖励 = 内容轮基础量 × 倍率 |
| 专属机制 Signature | 每系唯一的资源条或触发规则，是区别于他系的核心玩法来源 |
| 硬性限制 Restriction | 每系一条不可绕过的约束（槽位上限/禁用类别/数量上限），对标 Brotato |
| 属性基线 Baseline | 角色进入单局时的初始属性方案，`TbAttributeProfile` 按角色配置 |
| 卡池权重 Weight | 升级三选一时本系倾向武器/被动的出现概率倍率 |
| 超武形态 Ultimate | 武器 5★ + 对应被动 ≥1★ + **开启宝箱** 后的质变形态 |
| Limit Break | 超武之后的额外成长，每级 +15% 该武器攻击贡献，上限 +3 级 |
| 强度预算 Budget | 局内成长与局外养成对总战力的贡献占比，Σ = 1.0 |
| 局外品质 Quality | 白→绿→蓝→紫→金→红，控制局外成长，不进局内随机升级 |
| Pivot | 局内依商店/掉落运气中途改变 Build 方向（Brotato 社区术语） |

### 4.2 逐系详述

**磐岳 · 重装近战**
- 机制：每次受击积累怒气，满层进入 5 秒「铁壁」（减伤 30% + 近身持续伤害），怒气不清零可反复触发。
- 武器倾向：近战环形、短射程高命中 ×1.6；远程弹道 ×0.7。
- 被动倾向：承伤、反伤、生命回复、减伤 ×1.6。

**焚天 · 远程法术**
- 机制：同一目标连续命中叠加元素层，满 5 层触发范围爆裂；不同武器叠层独立。
- 武器倾向：弹道/穿透/群体 ×1.6；近战 ×0.6。
- 被动倾向：弹丸数量、穿透、范围、暴击 ×1.5。

**惊鸿 · 高速连击**
- 机制：命中累计连击数，越高攻速倍率越高（上限 +40%）；脱战 2 秒衰减。
- 武器倾向：高频短 CD ×1.7；重击类禁用。
- 被动倾向：攻速、移速、闪避、连击增益 ×1.6。攻速上限设 2.0（间隔 0.25s），性能压测后回写。

**御灵 · 召唤仆从**
- 机制：击杀精英/特殊掉落积累魂力，消耗召唤继承本体 60% 属性的仆从，上限 3，自动索敌、不触发拾取。
- 武器倾向：召唤/持续类 ×1.8；纯本体输出 ×0.6。
- 被动倾向：仆从数量、强度、持续时间 ×1.7。

**周天 · 领域持续**
- 机制：技能命中地面留下持续伤害区域，多区域叠加并互相引爆，离开后仍持续 6 秒。
- 武器倾向：目标位置/范围类 ×1.8；单体弹道禁用。
- 被动倾向：区域半径、持续时间、引爆伤害 ×1.7；同类已持有 ≥3 时权重递减。

**天机 · 增益拾取**
- 机制：拾取半径 +50%，每拾取 N 个经验球触发全局增益（短时伤害 +15%），金币 +30%。
- 武器倾向：无强倾向（×1.0），增益类被动 ×1.8。
- 被动倾向：拾取半径、经验、金币、增益时长 ×1.8。

## 5. 战斗公式与属性体系

### 5.1 现有公式（实测）

| 环节 | 公式 |
|---|---|
| 伤害 | `D = floor(ATK² / (ATK + DEF·k) × rand/10000) × (暴击 ? 1.5 : 1)` |
| 命中率 | `Hit·Hp / (Hit·Hp + Ev·Ep)` |
| 暴击率 | `Crit·Cp / (Crit·Cp + CritRes·Cp')` |
| 攻击间隔 | `max(baseInterval / AttackSpeedMultiplier, 0.05)` |
| 减伤（推导） | `DR% = DEF·k / (敌人攻击 + DEF·k)` |
| 常量 | 随机 8000~12000bp（期望 1.0）、暴击 1.5×、最短间隔 0.05s、受击无敌 0.5s、60Hz |

### 5.2 结构性风险与处置

| 级别 | 风险 | 处置 |
|---|---|---|
| 🔴 P0 | 玩家基准 Defense/Critical/Evasion 全为 0，**百分比偏移无效** | 已改绝对增量 |
| 🔴 P0 | 减伤随敌人攻击力衰减，高防系「割草无双、Boss 平庸」 | 角色品质对防御的放大**取半**；后续给敌人加 AttackParameter 分档 |
| 🟡 P1 | 普通怪 Defense=0，伤害退化为线性 ATK | M2 扩展怪物时给中后期怪配置递增 Defense（0→3→6→10） |
| 🟡 P1 | 暴击需 Crit≈33 才有 25% 率 | 已按 `Crit/(Crit+100)` 建模标定 |
| 🟢 P2 | 攻速下限 0.05s 是硬性天花板 | 惊鸿攻速上限设 2.0，性能压测后回写 |

## 7. 局外养成与强度预算

### 7.1 三条养成线（修仙题材化）

> 局外养成确定为：**境界提升 / 法宝（带词条） / 天赋树**。原「角色品质 / 武器品质 / 装备槽」三层包装全部映射到这三条线，**数值口径不变**。
> **资源获取通道**另有两条：① 修为挂机（境界的输入）② 幸运转盘（境界经验/装备/法宝/材料）—— 均**在线才有效**。

| 养成线 | 原映射 | 作用 | 进公式 |
|---|---|---|---|
| ① 境界提升 | 角色品质 | 属性基线（生命/攻击/防御）+ 解锁上限 | 是 |
| ② 法宝 + 词条 | 武器品质 + 装备槽 | 分槽位提供攻击/生存/机动/功能 | 是 |
| ③ 天赋树 | 永久天赋 | 三分支数值与机制节点 | 是 |
| ④ 卡池与选项 | 账号等级/章节 | 资格、权重、初始阶数、操作权 | **否（内容层）** |
| 资源通道 A | — | 修为挂机（在线每 10s 结算，渡劫突破） | 否（资源输入） |
| 资源通道 B | — | 幸运转盘（局内宝箱钥匙 → 局外转盘） | 否（资源输入） |

### 7.3 境界提升

**结构**：9 大境界 × 4 小阶（初期/中期/后期/圆满）= 36 阶。每小阶 **+0.40%** 属性基线，每大境界 **+1.9%**（等比，1.15^(1/35)）。

| 大境界 | 起点系数 | 解锁内容 |
|---|---:|---|
| 炼气 | 1.000 | 本命法宝槽 ×1 |
| 筑基 | 1.019 | 护身法宝槽 |
| 金丹 | 1.038 | 遁光法宝槽 |
| 元婴 | 1.057 | 灵辅法宝槽（全开）+ 卡池 T1 |
| 化神 | 1.076 | 天赋点 +2 |
| 炼虚 | 1.095 | 卡池 T2 |
| 合体 | 1.115 | 超武前置 T3 |
| 大乘 | 1.134 | 天赋点 +2 |
| 渡劫 | 1.150 | 难度档解锁 |

**修为产出**（输入侧，两条通道）：

| 通道 | 机制 | 与 §3.7 关系 |
|---|---|---|
| 单局结算 | 存活时间 + 击杀数 + Boss 进度折算修为（离线亦生效，仅一次） | 已有 |
| **在线打坐** | **每 10 秒结算一次**修为进度 = 基础值 × 境界系数 × 加成；**离线即停** | 与 16h AFK 巡逻挂机性质不同：这是**主动在线挂机**，不产生离线产出 |

打坐产出基数占位（待定）：基础 200/10 秒，境界系数与境阶挂钩（炼气 1.0 → 渡劫 1.5），加成分项：灵根加成（图1示例 +50%）/ 阵位加成（+30%）/ 丹药加成（+20%）。

**渡劫机制**：修为进度满（每大境界需 1 段进度）时主动触发"波动"按钮（参考图1右下方闪电图标），进入渡劫动画。
- **成功**：晋升下一境界，进度条重置为 0；
- **失败**：降回当前境界 30%~50% 进度（不重置境界），但**保留已结算的天赋点与法宝**。
- 渡劫成功率默认 100%（首破），每大境界首次突破后可解锁"困难渡劫"模式（成功率 50%，奖励双倍修为 + 稀有宝箱钥匙）。

**资源通道 B：幸运转盘**（独立于打坐）

> **机制修正（V1.0+）**：每次固定消耗 **1 把钥匙**，不是按倍率多耗。结果由**两个独立随机的维度组合**决定：
> ① **内容轮**（转哪个格子 → 奖励内容）② **倍率轮**（天机倍率 ×1/×2/×3/×5/×10 → 数量）。
> 最终奖励 = 内容轮命中格的基础量 × 倍率轮命中倍率。

| 项 | 设计 |
|---|---|
| 钥匙来源 | 局内开宝箱时记录获得，**1 个宝箱 = 1 把钥匙** |
| 单次消耗 | **固定 1 钥匙**（不随倍率变化） |
| 维度① 内容轮 | 8 格：4 稀有位（九天玄机鼎 / 太虚神晶 / 混元玉葫 / 玄天秘匣）+ 4 普通位（修为 / 洗炼材料 / 装备材料 / 灵石） |
| 维度② 倍率轮 | ×1 / ×2 / ×3 / ×5 / ×10，独立抽取，UI 右上角实时显示「天机倍率 ×N」（图2） |
| 奖励类型 | 境界经验（突破小阶）、法宝品阶材料、词条洗炼材料、装备材料 |
| 独立随机 | 两轮互不影响，可出现「稀有位 ×10」的高光时刻，也可出现「普通位 ×1」的保底 |

**权重与期望**（占位值，需实测校准）：

| 倍率 | 权重 | 内容轮 | 权重 | 稀有系数 |
|---|---:|---|---:|---:|
| ×1 | 40% | 普通位 ×4 | 各 20%（共 80%） | 1.0 |
| ×2 | 30% | 稀有位 ×4 | 各 5%（共 20%） | 2.0~3.0 |
| ×3 | 15% | | | |
| ×5 | 10% | | | |
| ×10 | 5% | | | |

- 倍率期望 = 1×0.40 + 2×0.30 + 3×0.15 + 5×0.10 + 10×0.05 = **2.45**
- 内容期望系数 = 0.80×1.0 + 0.20×2.5 = **1.30**
- 单次期望产出 = 基础量 × 1.30 × 2.45 = 基础量 × **3.185**

**经济等价标定**（占位）：

| 项 | 数值 |
|---|---|
| 打坐产出 | 200/10s × 境界系数 ≈ 1200/分钟 ≈ 72,000/小时 |
| 日均在线挂机 | 2 小时 → **约 144,000 修为当量** |
| 单局宝箱数 | 约 6 个 → 6 钥匙/局；日均 3 局 → **18 钥匙/天** |
| 转盘基础量 | **2,500 修为当量**（18 × 2,500 × 3.185 ≈ 143,000） |

→ 两条通道日均产出基本 1:1，互为补充而非替代：想快就多打局拿钥匙，想稳就挂机。

**经济敏感性**（日均 18 钥匙基准，纯计算，参数全部落表可调）：

| 调节项 | 变化 | 日均产出 | 对比打坐 144,000 |
|---|---|---:|---:|
| 基准组（40/30/15/10/5 + 稀有20% + 基础量2500） | — | 143,325 | **−0.5%（自平衡）** |
| ×10 权重 5%→8% | 期望倍率 2.45→2.69 | 157,190 | +9.2% |
| ×10 权重 5%→10% | 期望倍率 2.88 | 168,480 | +17.0% |
| 稀有位权重 20%→30% | 内容期望 1.45 | 159,862 | +11.0% |
| 宝箱 6→8/局 | 钥匙 18→24 | 191,100 | +32.7% |
| 基础量 2500→3000 | — | 171,990 | +19.4% |

**结论**：
1. 基准参数组**自平衡**，无需初始调参。
2. **调节杠杆排序：钥匙收入 > 倍率权重 > 稀有位权重 > 基础量**。×10 权重每 +1% ≈ 日均产出 +4%，是最锋利的旋钮；钥匙收入（宝箱数/局数）动一格就是 ±33%。
3. 后续调优应**先锁钥匙收入节奏，再调倍率权重做手感**，最后用基础量做全局校平。

**境界进度模拟**（日均 3 局 + 2 小时打坐，修为需求 16000 × 1.12^i）：

| 里程碑 | 天数 |
|---|---:|
| 炼气圆满 / 筑基圆满 | 第 1 天 |
| 金丹圆满 | 第 2 天 |
| 元婴圆满 | 第 3 天 |
| 化神圆满 | 第 4 天 |
| 炼虚圆满 | 第 7 天 |
| 合体圆满 | 第 11 天 |
| 大乘圆满 | 第 17 天 |
| 渡劫圆满 | **第 27 天（≈80h）** |

→ 与 §7.7「满养成 80h」**互相印证**：前期 1 天 2 大境界（成长爽感），后期 5~10 天一大境界（长线目标）。若后期偏长，优先把修为需求曲线 1.12 放缓至 1.10（表内 `requiredCultivation` 直接调），而不是砍打坐产出。

**设计要点**：
1. 修为打坐（在线被动积累） + 渡劫（主动风险决策） + 转盘（局内→局外资源回流）三件套，构成**完整的局外修仙节奏**：挂机积累 → 主动突破 → 资源博弈。玩家必须在线参与局内战斗获得钥匙 + 在线挂机积累修为，**离线什么都不会发生**。
2. 转盘「单钥匙 + 双维度」的设计让每次抽取都有**双重悬念**（转到什么 + 翻几倍），稀有位 ×10 是天然的高光时刻与传播点，成本却恒定——比「倍率越高越贵」更容易让玩家持续投入。
3. 渡劫失败不重置境界，只掉进度——**保证不会因为暂时离开而崩盘**，符合 Steam 单机的"内容目标驱动"。
4. 幸运转盘与 O2（局内经济/商店）共构双决策系统：转盘在局外、商店在局内，二者通过「钥匙」互通。

### 7.4 法宝与词条

**4 个槽位**，每槽有固定主属性方向，由境界解锁：

| 槽位 | 解锁境界 | 主属性 | 满配贡献（道器 6 词条） |
|---|---|---|---|
| 本命法宝 | 炼气 | 攻击贡献 | ×1.22 |
| 护身法宝 | 筑基 | 生命 / 防御 | 生命 +10%、防御 +2 |
| 遁光法宝 | 金丹 | 移速 / 闪避 | 移速 +8%、闪避 +5 |
| 灵辅法宝 | 元婴 | 经验 / 拾取 / 经济 | 经验 +15%、拾取 +20%、Reroll 费用 −30% |

**品阶 6 阶**（法器 / 宝器 / 灵器 / 仙器 / 神器 / 道器），词条数与强度同步提升：

| 品阶 | 词条数 | 贡献系数（相对满配） |
|---|---:|---:|
| 法器 | 1 | 0.15 |
| 宝器 | 2 | 0.30 |
| 灵器 | 3 | 0.45 |
| 仙器 | 4 | 0.62 |
| 神器 | 5 | 0.80 |
| 道器 | 6 | 1.00 |

单件法宝实际贡献 = 该槽满配贡献 × 贡献系数。例：本命法宝·仙器 = ×(1 + 0.22 × 0.62) = ×1.136。

**词条类型与数值范围**（单条，随品阶）：

| 类型 | 词条示例 | 单条范围 |
|---|---|---|
| 攻击 | 攻击力、暴击值、暴击伤害、攻速、穿透、伤害加成 | +2.0% ~ +6.0% |
| 生存 | 生命、防御、闪避、生命回复、减伤、免疫次数 | +2.0% ~ +6.0% |
| 机动 | 移速、拾取半径 | +1.5% ~ +4.5% |
| 功能 | 经验获取、金币获取、Reroll 折扣、开局星级 +1 | 固定值，按词条表配置 |

**洗炼（重铸）**：消耗材料随机重掷单条词条数值，**低成本高频**（对标 Brotato 1 金 Reroll 的思路）。这是法宝系统的长线追求点与资源消耗口。

**设计要点**：词条 = 法宝系统的可玩性来源。品阶决定词条**数量**（纵向成长），洗炼决定词条**质量**（横向打磨），两者分离，避免纯数值堆叠。

### 7.5 天赋树

三分支，对应修仙语汇：

| 分支 | 定位 | 节点效果 |
|---|---|---|
| 杀伐 | 输出 | 攻击、暴击、暴击伤害、攻速、穿透 |
| 长生 | 生存 | 生命、防御、闪避、生命回复、减伤 |
| 机缘 | 功能 | 经验、金币、拾取半径、Reroll 折扣、锁定次数 |

**结构**：每分支 6 层，每点 **+0.67%**（18 点填满一分支 ≈ +12%）。第 6 层为**机制节点**，不给数值：

| 分支 | 末端机制节点 |
|---|---|
| 杀伐 | 超武进化所需宝箱数 −1 |
| 长生 | 每局首次致死伤害免疫 1 次 |
| 机缘 | 每局额外 1 次免费 Reroll |

**点数产出（V1.0 修订）**：**每次境界突破后可点 1 点**（36 小阶 = 36 点）+ 图鉴/成就 8 点 = **总上限 44 点**。三分支共 44 个节点，全点满 = **×1.12**，每点平均 **+0.26%**（对数口径，节点数值 0.2%~0.4% 按层递增，第 6 层为机制节点不占数值预算）。

> ⚠️ 法宝相关数值**暂缓标定**：法宝层的数值（攻击 ×1.22 + 生命 +10%）**等局内三选一卡池定稿后再校准**，届时重跑 `meta_model.py` 复核 75/25 预算。本节数值不受影响。

**设计要点**：天赋树只提供**效率与机制**，不提供能力解锁（Skip 默认开放、Reroll 局内金币购买），与 §8.4 一致。
