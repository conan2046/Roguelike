# 第二章：V1.1 第六章建议中的错误（自我撤回）

## 2.1 撤回：将 `SynchronizeAttributes` 抽为存档快照接口

**错误方向**。`SynchronizeAttributes` 是 ECS 运行态同步方法，不是持久化 DTO。直接复用会把存档格式绑死在战斗内核结构上，日后重构战斗内核即破坏存档兼容。

**修正**：存档层应定义独立的持久化 DTO，由协调器显式映射，不复用运行态结构。

## 2.2 撤回："存档绝不存配置快照"

**过于绝对**。跨版本续局至少需要保存：`saveSchemaVersion + contentVersion + seed + 固定 tick + 全部序列计数 + 稳定 ID`。若要求补丁后保持原局结果，还需保存已解析运行态值或冻结旧配置版本。

## 2.3 撤回：P0 新增 `DiminishingReturn` 枚举

**逻辑跳跃**。把收益曲线塞进通用 modifier enum 混淆了三件事：

| 层次 | 问题 | 解法 |
|---|---|---|
| 玩法平衡 | 属性收益是否递减 | 属性专属曲线配置 |
| 工程安全 | 整数/浮点是否溢出 | 类型与溢出边界测试 |
| 内容约束 | 极端 Build 是否被允许 | 组合上限与配置校验 |

三者需要不同的表结构与测试，不能靠新增枚举解决。

## 2.4 撤回："Steam 平台集成清单均为发行必须项"

不准确。Steamworks 功能可按产品选择；硬要求是**商店页声明的功能必须在送审版本实现**，而非所有游戏都需成就/云存档/创意工坊。

## 2.5 修正：Steam 崩溃上报

原表述"Steam 不提供崩溃统计"不准确。Steam 有 Error Reporting，但已接近停止支持且只支持 Windows 32 位，对当前 Win64 项目仍需另选方案。结论方向不变，依据需修正。

# 第三章：发布风险清单（V1.1 第六章重写）

> 重写原则：从"经验文章"改为**可自动验收的条目**。每条给出验收判据，而非建议。
> 优先级对齐 `docs/rouge-feature-backlog-and-priority.md` 真实里程碑（M2 / M3 / M4 / M5）。

## 3.1 运行生命周期契约（P0）

启动、暂停、失焦、休眠、恢复、异常退出、正常结算、强退分别何时落盘；Steam Deck 休眠前后 Run Save 一致性。

**验收判据**：每个状态转换有对应用例，`MCPDemo`/正式场景均覆盖；强退后重进可恢复到最近一次合法落盘点。

## 3.2 存档提交协议（P0）

三文件分片会产生跨文件撕裂，需 generation/manifest 或事务日志。覆盖：多存档槽、滚动备份、校验和、磁盘满、无权限、非 ASCII 用户路径、降级版本拒绝。

**验收判据**：写入过程中断电/强杀，重启后存档处于"旧档完整"或"新档完整"二者之一，不存在中间态。

## 3.3 确定性边界（P0）

`CombatRandom` 的 purpose 分流只保证**随机抽样可复现**，不等于**整局可复现**。还需锁定：实体遍历顺序、浮点策略、Jobs/Burst 差异、配置版本、全部 sequence counter。

**验收判据**：中途快照 → 恢复 → 最终状态哈希一致。

## 3.4 Steam 构建与回滚（P0）

AppID / DepotID / beta branch / BuildID / manifest / 版本号 / 符号文件 / 回滚 / 增量补丁大小 / 干净安装验证。

## 3.5 Demo 与正式版边界（P0）

Demo 是**独立 AppID**，不是编译开关。需定义共享 depot、共享云存档、解锁继承与内容裁剪。

## 3.6 Steam 不可用与离线降级（P1）

API 初始化失败、客户端未启动、离线模式、成就提交失败时游戏是否仍可玩；成就需幂等、本地排队、重试。

## 3.7 资源所有权与异步取消（P1）

YooAsset Handle、ECS World、NativeContainer、Scene 切换、初始化中途取消、异常清场的所有权矩阵与泄漏测试。

**注**：`AGENTS.md` 要求审查资源所有权，V1.1 只写"加载释放成对"，粒度不足。

## 3.8 输入完整协议（P1）

手柄热插拔、多控制器、死区、长按连发、重映射冲突、控制器字形、鼠标手柄切换、屏幕键盘。Deck Verified 要求全功能默认控制、正确字形、文本输入方案、800p 基线。

## 3.9 设置、显示、音频与无障碍（P1）

设备相关设置不得进 Cloud；窗口/无边框/DPI/超宽屏/多显示器；音量分组与音频设备变化；字幕、字号、色弱、闪烁与镜头震动开关。

## 3.10 隐私与诊断治理（P1）

崩溃上报与遥测的用户告知、最小采集、脱敏、保留周期、离线队列、BuildID/符号上传。

## 3.11 补丁兼容 QA 矩阵（P1）

干净安装、旧版本升级、跨两版本升级、回滚、坏档、云冲突、低磁盘、断电、Deck 休眠、Steam 离线、首次无网络。

## 3.12 供应链与发布安全（P2）

Unity Package / Git 包固定版本、许可证、构建账号与 Steam 上传凭据隔离、第三方 SDK 升级回滚策略。
