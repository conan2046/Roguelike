# 借劫炼器切片：交付与验证记录

2026-10-26。交付范围为可在 Unity Editor 体验的小切片；人工手感验收和数值终调待用户体验反馈，不作为正式发行完成声明。

## 如何体验

- 当前工程菜单：`Roguelike/启动/借劫炼器切片`；技术启动参数为 `-tribulation`，职业及关卡列表读取 Luban 入口表。
- 选择磐岳或周天，WASD / 方向键移动，角色自动施法；Esc 暂停，R 在结算后重开。
- 雷坛在模拟时间 15 / 65 / 115 秒解锁。靠近金色圆环后点击“引动天劫”，将锁点落雷引向怪物并避开红圈。
- 存活完成试炼且达到真实雷击命中目标后，三选一重炼本命法器；星级保留，下次成功可以转向其他分支。
- 4 分钟进入劫狱执印者战斗。Boss 随生命进入三个阶段，最后阶段雷击会清除相交阵域。局内、领奖和结算都能返回选角。

以上时点只是本切片当前源表值，不是代码默认值；后续调整以源 Excel 为准。

## 实际游玩证据与技术夹具的区别

1. **磐岳正常完整链**：正式菜单 → UI 射线选角 → 输入帧移动 → 雷坛真实点击 → 雷击有效命中 11 次 → 渡劫 → UI 领取连梭 → 升星仍保留道途 → Boss 三阶段 → 正常 Boss 死亡与胜利。结算模拟时间 4:18、击杀 201、等级 9、剩余生命 49。没有注入生命、经验、击杀或胜利；输入驱动按正常固定 tick 快速回放。
2. **真实失败与重开**：多次自然失败后通过结算按钮重开；自然胜利后也通过按钮重开，生命、预警、雷坛及旧代次均恢复。返回选角后 World 数从战斗状态恢复为入口基线 6，EventSystem 为 1。
3. **周天正常机制和领奖**：实际移动触发留阵、脉冲和折返引爆，一次过程观察到 40 次引爆；真实渡劫命中 7 次并到达炼器面板。最终整数治疗实测为 14 → 35。周天没有被本报告描述为已经自然通关。
4. **Boss 破阵技术边界**：独立原生会话测试把 Boss 布置在第三阶段生命边界，随后由正式协调器推进真实预警、暂停、范围伤害和未到寿命阵域清除。这是受控边界证据，不冒充另一条自然通关。
5. **最终界面复测**：最终代码再次正常渡劫，炼器面板上的返回按钮通过真实 UI 射线；不领取奖励也能关闭旧战斗并恢复可选的两职业入口。
