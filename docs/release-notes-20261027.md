# 本地战斗迭代整理记录

本次将上次提交以来累积的本地修改按依赖关系整理入库。源配置、Luban 生成代码、运行时 bytes 与消费代码一并提交；不构建 Win64 包，不将本机验收缓存上传到远端。

## 当前实现

- 表驱动局内武器、被动、升星、进化、升级候选、事件精英与宝箱奖励，配套正式 UI、配置工具和回归用例。
- 借劫炼器双角色切片及选角入口，包含雷坛、预警、炼器选择、职业能力、阵域和 Boss 阶段。
- 弹丸飞行与命中特效、独立模型与技能片段层级、Prefab Inspector 导出到 Luban，以及命中特效跟随目标挂点。死亡或槽位复用后在最后位置播完，不附着到新目标。
- 镜头视野高度由配置驱动；Ground 按完整行走范围加完整可见视野生成，并在比例变化时重铺。当前试炼地图 ID 101 的半宽、半高均为 2000；编辑器试玩中自动显示红色行走边框，退出即回收。
- ECS 移动与表现桥修复、血条稳定排序与合批，以及资源包职责拆分与离线构建前置门禁。
- 保留手调技能 Prefab、正式 UI 资源、编辑器工具、数值脚本、历史策划与架构审查资料。旧审查文档是阶段记录，以本页和对应最新报告识别当前状态。

1. 战斗切片与配置：运行代码、正式资产、源表、生成代码、bytes、配置验证工具及相关测试作为一个可编译依赖闭包。
2. 工程工具：测试、性能采样、构建脚本、静态审计与数值计算工具。启动脚本从自身路径定位项目，通过参数或环境变量指定 Unity Editor。
3. 文档：功能方案、策划参考表、架构审查、性能报告和交接记录，以及本次整理说明。
4. 仓库维护：多 Unity 工程隔离规则、本机缓存忽略、已删除截图目录元数据，以及 Unity 自动补全的平台图标序列化记录。
