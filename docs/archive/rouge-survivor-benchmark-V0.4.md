# rouge 对标《吸血鬼幸存者》《土豆兄弟》的优化决策 V0.4

> 输入：VS / Brotato 公开设计与社区数据（2026-09-09 检索）+ GameRes《肉鸽为什么让人输完还想重开》+ 本项目现状。
> 目的：找出 rouge 与两款标杆的**结构性差距**，给出确定修改项，并回写到既有设计文档。
> 关联修改：`rouge-six-class-design-V0.1.md`（六系加硬性限制）、`rouge-meta-progression-numerics-V0.3.md`（Reroll 下放 + 预算改 75/25）、`rouge-feature-backlog-and-priority.md`（新增模块与排期）。

## 1. 结论先行

1. **两款标杆共同的方向是「局内策略优先」**：Brotato 明确把重心从 Meta 养成转到商店决策，VS 的 PowerUp 也只占约三成。我们 V0.3 定的 **70/30 方向正确**，且加入「超武后 Limit Break」后可进一步收敛到 **75/25**（实测合计 4.30x）。
2. **我们最大的结构性缺口不是随机，而是「决策系统太少」**：VS 有三选一 + 宝箱 + 地图道具；Brotato 有三选一 + **波间商店 + 经济**。我们只有三选一。
3. **第二缺口是「没有可追逐的局内目标」**：VS 的进化需要开宝箱触发，形成「去哪儿开箱」的动机。我们的超武是自动触发，缺少这一层。
4. **第三缺口是没有重复可玩的难度梯度**：Brotato Danger 0~5、VS Hyper/Inverse，我们没有。
5. 本轮确定 **8 项修改**，其中 4 项进 P0/P1，4 项进 P2。

## 2. 竞品拆解（只列可迁移的机制，不列内容量）

### 2.1 Vampire Survivors

| 机制 | 具体做法 | 作用 |
|---|---|---|
| 6 武器 + 6 被动槽 | 槽位即 Build 边界 | 与本项目框架一致 |
| **进化需开宝箱触发** | 武器满级 + 对应被动 + **开宝箱** | 给随机一个「可追逐的地理目标」 |
| Union / Gift 形态 | 双武器合体、额外形态 | 进化之外的第二层质变 |
| 主动拾取经验 | 经验球需走过去吃 | 「逃离 vs 靠近」的拉锯张力 |
| 组合不告知 | 隐藏配方由玩家自己发现 | 社区传播与探索动机 |
| 每 5 分钟精英 / 10 分钟 Boss / 30 分钟死神 | 显式里程碑 | 可预期的节奏与紧张点 |
| 局外 PowerUp + 金蛋 | 永久强化占约三成；金蛋为无限微量成长 | 长线但不碾压 |
| 模式：Hyper / Inverse / Daily / Adventure | 同一关卡多种打法 | 重复可玩 |

### 2.2 Brotato

| 机制 | 具体做法 | 作用 |
|---|---|---|
| 6 武器同时装备 | 同类型武器叠加放大 | 极端 Build 爽感 |
| **波间商店** | 每波结束可买武器/道具/属性 | **第二个决策系统** |
| **Reroll 仅 1 金** | 极低门槛 | 让「再选一次」成为日常操作而非稀有特权 |
| 材料经济 | 击杀掉材料， Harvesting 属性提升掉落 | 经济流派成立 |
| 属性叠加无上限 | +500% 伤害、+80% 闪避 | 后期数值爆发 |
| 角色 = 属性修正 + **硬性限制** | Crazy +50% 伤害但 +25% 受伤；Brawler 限远程 | 限制比加成更能制造差异 |
| Danger 0~5 难度梯度 | 通关解锁下一档 | 重复可玩核心 |
| Pivot（社区术语） | 依商店运气中途改 Build | 局内策略优先于长期养成 |
| 极简美术 | 满屏弹幕仍可读 | 可读性优先 |

## 3. 差距对照与优化决策

| # | 维度 | VS | Brotato | rouge 现状 | 决策 | 优先级 |
|---|---|---|---|---|---|---|
| O1 | 超武触发 | 开宝箱 | 武器合成升稀有 | 5★+被动自动触发 | **改为「需开宝箱/精英掉落触发」**，形成可追逐目标 | **P0** |
| O2 | 第二决策系统 | 宝箱/地图道具 | 波间商店 | 无 | **局内经济 + 商店**升级为核心模块，非点缀 | **P0** |
| O3 | Reroll 成本 | Arcana 解锁 | **1 金** | 局外天赋解锁 | **下放为局内基础能力（金币购买）**；Lock 保留局外解锁；Skip 默认开放 | **P0** |
| O4 | 角色限制 | 属性修正 + 代价 | **硬性限制** | 只有属性修正与代价 | **六系各加一条硬性限制** | **P1** |
| O5 | 后期数值上限 | Might 上限 1000% | 属性无上限 | 星级 1~5★ 封顶 | **超武后 Limit Break**（+3 级），保留爆发与长线 | **P1** |
| O6 | 难度梯度 | Hyper/Inverse/Daily | Danger 0~5 | 单一关卡 | **通关解锁难度档**（M4 后） | P2 |
| O7 | 里程碑节奏 | 5/10/30 分钟 | 5/10/15/20 波 | 四阶段刷怪 + 18 分钟 Boss | **显式里程碑 + UI 提示**（5/10/15/18 分钟） | P1 |
| O8 | 经验拾取张力 | 需走过去吃 | 自动拾取 | 经验吸附（半径待定） | **克制吸附半径**，保留「靠近 vs 逃离」拉锯 | P2 |

### 3.1 O1 超武仪式化（结合 near-miss）

VS 的进化三条件中，「开宝箱」是唯一需要玩家**主动前往**的条件。改为该机制后：

- 超武条件：`武器 5★ + 对应被动 ≥1★ + 开启宝箱/精英掉落宝箱`
- 直接产出 near-miss：玩家死在 5★ 但没开到箱子 → 「差一个宝箱」。
- 结算页显式提示：`再开 1 个宝箱即可进化 XXX`（对应 GameRes 文档的「差一点成型」）。
- 副作用：宝箱成为地图事件的核心价值点，与 #7 局内事件模块天然咬合。

### 3.2 O2 局内经济与商店

| 项 | 设计 |
|---|---|
| 货币 | 局内金币（击杀/精英/宝箱产出），**不结转局外**（局外另用能量块，保持两套分离） |
| 商店出现 | 地图事件节点 + 固定时间点（建议 6 / 12 分钟各一次） |
| 售卖内容 | 武器（补槽）、被动、属性词条、**重 roll 券**、血包 |
| 定价 | 随局内时间递增，防止早期碾压 |
| Reroll | **固定低成本**（对标 Brotato 的 1 金），局内可反复购买 |
| 与 Build 关系 | 商店是「Pivot」发生地：允许玩家中途改流派 |

### 3.3 O3 三选一操作权重新分配

| 操作 | 原方案（V0.3） | 修订后 | 理由 |
|---|---|---|---|
| Skip（跳过） | 章节 3 解锁 | **默认开放** | 「不拿也是选择」是最基础的设计语言，不该锁 |
| Reroll（重选） | 天赋节点解锁 | **局内金币购买，低门槛** | 对标 Brotato 1 金；决策权应发生在局内 |
| Lock（锁定） | 天赋节点解锁 | 保留局外解锁 | 锁定是强能力，适合作为养成奖励 |

> 局外天赋改为解锁 **折扣 / 次数上限**（如「Reroll 费用 −50%」），而非解锁能力本身——保持局外是「优化」不是「解锁」。

### 3.4 O4 六系硬性限制（写入 V0.1）

| 系 | 加成 | **新增硬性限制** |
|---|---|---|
| B_0 重装 | 生命/防御高 | **武器槽上限 4**（其余 6 槽），换单件强度 +15% |
| H_0 法术 | 攻击/暴击高 | **被动槽上限 4**，换被动效果 +20% |
| J_0 连击 | 攻速/闪避高 | **不能装备「重击类」武器**（慢速高伤） |
| K_0 召唤 | 仆从乘区 | **仆从上限 3**（原设计 4），且仆从不触发拾取 |
| Y_0 领域 | 领域乘区 | **无单体弹道武器**，只能带范围/目标位置类 |
| Z_0 增益 | 拾取/经验/移速 | **武器槽上限 5**，但每次升级额外获得 1 金币 |

> 设计原则（Brotato 验证）：**限制比加成更能制造差异**。加成让玩家变强，限制让玩家换一种玩法。

### 3.5 O5 Limit Break 与预算重算

超武后开放 Limit Break，每级 +15% 武器攻击贡献，上限 3 级（需局内条件解锁，非自动）。

| 状态 | 加权战力 | 相对新号 |
|---|---:|---:|
| 新号 | 61.5 | 1.00x |
| 局内满（6 武器 5★） | 137.2 | 2.23x |
| + Limit Break ×3 | 185.7 | 3.02x |
| 全满（含局外） | 264.0 | **4.30x** |

**预算占比：局内 76% / 局外 24%**（原 70/30）→ 更贴近 Brotato 的「局内策略优先」。建议目标定为 **75 / 25**。

## 6. 诚实边界

- 竞品数据来自公开 Wiki / 媒体 / 社区（VS Wiki、EarlyGuides、Shapes Fandom、游民星空、52xz），**部分为中文二手转述，未经一手实测**，具体数值（如 Reroll 1 金、+500% 伤害）应以上手实测为准。
- **O1/O2 属新增系统**，工作量与现有 M2/M3 排期叠加，需重新评估工期；本文只给设计决策，未做排期细化。
- Limit Break 的 +15%/级 ×3 为**模型占位值**，未与「18 分钟单局时长」联合校验——若后期过强，应优先压缩次数而非单级数值。
- 六系硬性限制会改变 V0.2 的平衡结果（槽位减少 → 系别实际强度下降），**需在限制定稿后重跑 `Tools/Numerics/class_balance_model.py`**。
- O8 经验吸附半径的建议值未给出，需实测「捡取压力 vs 挫败感」后确定。
