# rouge 六系职业（角色）差异性与职业特色设计 V0.1（草案 · 系名待定）

> 上游：`rouge-functional-framework.md`（M0 已关闭，USP 三支柱）、`rouge-feature-backlog-and-priority.md`（优先级 #2/#3/#4/#5）。
> 状态：**草案**。六系中文名待项目方给定后替换（当前用资源前缀 B/H/J/K/Y/Z + 原型代号）。
> 范围：机制 + 卡池 + 属性基线三层差异化，**不含**专属技能具体数值、局外养成（留 M3/M4）。

## 1. 设计目的

1. 让 6 个角色在「同框架不同体验」下成立：共用一套战斗底座、升级卡池与超武规则，但每系有**不可替代的核心机制**，避免"换个模型的数值差异"。
2. 差异化落在**可感知层**（开局 30 秒能感觉到），而非面板数字：每系一个专属资源/触发机制 + 一个属性基线偏移 + 一组卡池权重。
3. 与 USP 三支柱对齐：① 低操作门槛自动割草不受职业差异破坏；② 超武进化链按系别分化形态；③ 图鉴/收集以"六系 × 收集度"驱动长线。
4. 全部差异进入 Luban 表（角色系别、属性方案、卡池权重），代码零硬编码。

## 2. 名词解释

| 术语 | 定义 |
|---|---|
| 系别 Element | 角色的战斗原型归属，决定专属机制、属性基线与卡池权重；全局共 6 系 |
| 专属机制 Signature | 每系唯一的资源条或触发规则，是该系区别于他系的核心玩法来源 |
| 属性基线 Baseline | 角色进入单局时的初始属性方案，`TbAttributeProfile` 按角色配置 |
| 卡池权重 Weight | 升级三选一时，本系倾向的武器/被动出现概率倍率，混合卡池框架下的偏向参数 |
| 原型 Prototype | 六系在战斗节奏上的分工（爆发/持续/机动/召唤/领域/增益） |
| 超武形态 Ultimate | 武器 5★ + 对应被动 ≥1★ 后的质变形态，按系别分化表现与机制 |
| 系别纯度 Purity | 单局内本系武器/被动占已装槽位的比例，用作部分专属机制的强度系数 |
| 局外品质 Quality | 白→红，控制局外成长，不进局内随机升级（框架已定，不复用星级） |

## 3. 差异化模型（五维）

每系必须同时满足五个维度都有差异，且**只有第一维可以强**，其余为辅助，避免六系变成六个强度档。

| 维度 | 作用层 | 玩家感知 | 数据来源 |
|---|---|---|---|
| ① 专属机制 | 战斗规则 | 立即（30 秒内） | 新增 `TbCharacterSignature` 表 |
| ② 属性基线 | 数值 | 手感（移速/攻速） | `TbAttributeProfile` 每角色一份 |
| ③ 武器倾向 | 卡池 | 中期 Build 成型 | `TbUpgradePool` 权重列 |
| ④ 被动倾向 | 卡池 | 中期 Build 成型 | `TbUpgradePool` 权重列 |
| ⑤ 超武形态 | 峰值 | 单次质变 | `TbUpgradeOption` 进化分支 |

## 5. 六系详细设计

### 5.0 六系硬性限制（对标 Brotato，V0.4 新增）

> 原则：**限制比加成更能制造差异**。加成让玩家变强，限制让玩家换一种玩法。以下限制与 §5.1~5.6 的加成配套，缺一不可。
> ⚠️ 限制会改变 V0.2 的平衡结果（槽位减少 → 系别实际强度下降），定稿后需重跑 `Tools/Numerics/class_balance_model.py`。

| 系 | 加成（简） | 硬性限制 | 补偿 |
|---|---|---|---|
| B_0 重装 | 生命 +20%、防御 +4 | **武器槽上限 4**（其余 6 槽） | 单件武器强度 +15% |
| H_0 法术 | 攻击 +15%、暴击 13% | **被动槽上限 4**（其余 6 槽） | 被动效果 +20% |
| J_0 连击 | 攻速 +30%、闪避 9% | **禁止装备「重击类」武器**（慢速高伤） | 无 |
| K_0 召唤 | 仆从乘区 1.18 | **仆从上限 3**（原设计 4），仆从不触发拾取 | 单仆从强度 +12% |
| Y_0 领域 | 领域乘区 1.09 | **禁止装备单体弹道武器**，只能带范围/目标位置类 | 范围半径 +15% |
| Z_0 增益 | 移速 +10%、拾取 +50%、经验 +15% | **武器槽上限 5** | 每次升级额外获得金币 |

### 5.1 B_0 · 重装近战

| 项 | 设计 |
|---|---|
| 核心机制 | **受击蓄能**：每次受击积累「怒气」，满层后进入 5 秒「铁壁」——减伤 30% 且近身范围持续伤害；怒气不清零，可反复触发 |
| 属性基线 | 最大生命 140%、防御 130%、移速 90%、攻速 95%、攻击 95% |
| 武器倾向 | 近战环形、短射程高命中的武器权重 ×1.6；远程弹道 ×0.7 |
| 被动倾向 | 承伤、反伤、生命回复、减伤类 ×1.6 |
| 卡池规则 | 受击类被动在卡池中的保底出现率提升 |
| 超武方向 | 环形武器 → 环绕护体光圈（持续伤害 + 击退） |
| 风险 | 新手过强导致其他系无人选；用「清怪效率低于其他系」做平衡，不做数值削弱 |

### 5.2 H_0 · 远程法术

| 项 | 设计 |
|---|---|
| 核心机制 | **元素叠层**：同一目标连续命中叠加元素层，满 5 层触发爆裂（范围伤害）；不同武器叠层独立计算 |
| 属性基线 | 攻击 125%、攻速 100%、移速 95%、最大生命 85%、暴击值 +20% |
| 武器倾向 | 弹道/穿透/群体技能权重 ×1.6；近战 ×0.6 |
| 被动倾向 | 弹丸数量、穿透、范围半径、暴击 ×1.5 |
| 卡池规则 | 群体与弹道类武器优先进入候选 |
| 超武方向 | 主弹道 → 穿透光束（贯穿全屏） |
| 风险 | 后期弹幕覆盖过强；以「前 3 分钟成长慢」做窗口期劣势 |

### 5.3 J_0 · 高速连击

| 项 | 设计 |
|---|---|
| 核心机制 | **连击计数**：命中累计连击数，连击越高攻速倍率越高（上限 +40%）；脱战 2 秒后连击衰减 |
| 属性基线 | 攻速 130%、移速 115%、攻击 90%、最大生命 85%、闪避值 +15% |
| 武器倾向 | 高频短 CD 武器 ×1.7；重击/慢速武器 ×0.6 |
| 被动倾向 | 攻速、移速、闪避、连击增益 ×1.6 |
| 卡池规则 | 攻速与移速类被动权重提升，且可突破常规上限一档 |
| 超武方向 | 高频武器 → 残影分身（复制本体攻击） |
| 风险 | 攻速溢出导致性能压力；需与 #1 性能验证结果联动设上限 |

### 5.4 K_0 · 召唤仆从

| 项 | 设计 |
|---|---|
| 核心机制 | **仆从编制**：击杀精英/拾取特殊掉落积累「魂力」，消耗魂力召唤 1 只继承本体 60% 属性的仆从，上限 4 只；仆从自动索敌 |
| 属性基线 | 攻击 95%、最大生命 100%、移速 100%、仆从强度由专属属性控制 |
| 武器倾向 | 召唤/持续类武器 ×1.8；纯本体输出武器 ×0.6 |
| 被动倾向 | 仆从数量、仆从强度、仆从持续时间 ×1.7 |
| 卡池规则 | 仆从类选项在被动槽未满时保底出现 |
| 超武方向 | 召唤系超武 → 仆从合体为大型战魂 |
| 风险 | 实体数翻倍冲击性能；仆从上限需与千怪压测结果绑定 |

### 5.5 Y_0 · 领域持续

| 项 | 设计 |
|---|---|
| 核心机制 | **领域铺设**：技能命中地面留下持续伤害区域，多区域可叠加并互相引爆；本体离开后仍持续 6 秒 |
| 属性基线 | 攻击 100%、最大生命 95%、移速 90%、持续伤害加成专属属性 120% |
| 武器倾向 | 目标位置/范围类武器 ×1.8；单体弹道 ×0.6 |
| 被动倾向 | 区域半径、持续时间、引爆伤害 ×1.7 |
| 卡池规则 | 范围类武器在候选中的权重随已持有范围武器数递减（防同质） |
| 超武方向 | 领域武器 → 全场持续腐蚀场 |
| 风险 | 站桩收益过高；以铺设前摇与移速劣势做对冲 |

### 5.6 Z_0 · 增益拾取

| 项 | 设计 |
|---|---|
| 核心机制 | **拾取共鸣**：拾取半径 +50%，每拾取 N 个经验球触发一次全局增益（短时全体伤害 +15%）；金币掉落额外 +30% |
| 属性基线 | 移速 110%、最大生命 90%、攻击 95%、经验获取 +15% |
| 武器倾向 | 无强倾向（×1.0 全系通用），但增益类被动 ×1.8 |
| 被动倾向 | 拾取半径、经验、金币、增益时长 ×1.8 |
| 卡池规则 | 经济类被动优先出现；该系更容易在中期凑齐超武条件 |
| 超武方向 | 任意武器超武时额外获得一层共鸣增益 |
| 风险 | 后期无上限；以「本体输出属性偏低」约束 |

## 7. 卡池与 Build 规则联动

| 规则 | 设计 |
|---|---|
| 基础卡池 | 全系通用池，纯随机（框架已定混合卡池） |
| 系别偏向 | 本系倾向武器/被动权重 ×1.5~1.8；非本系 ×0.6~0.7 |
| 系别纯度 | 本系占槽比例 ≥4/6 时，解锁该系「纯度奖励」（如专属被动出现率 +30%） |
| 超武分化 | 同一武器在不同系下超武形态与表现不同，通过 `TbUpgradeOption` 的系别分支字段配置 |
| 反同质 | 同类武器已持有 ≥3 把时，该类权重逐档衰减，保证卡池多样性 |

## 8. 数据表扩展建议

| 表 | 新增/修改 | 说明 |
|---|---|---|
| `TbCharacter` | 新增 `elementId`、`prototypeTag`、`signatureId` | 系别、原型标签、专属机制 ID |
| `TbAttributeProfile` | 新增 6 份角色方案（ID 10~15） | 当前仅 1 份玩家调试方案（ID 1） |
| `TbUpgradePool` | 新增 `elementWeight` 权重列 | 按系别配置武器/被动权重倍率 |
| `TbUpgradeOption` | 新增 `elementTag`、`ultimateBranchId` | 系别标签与超武分支 |
| `TbAttribute` | 新增属性：拾取半径、经验获取倍率、金币获取倍率、持续伤害加成 | 现有 14 属性不含此四类，需扩展 |
| 新增 `TbCharacterSignature` | 专属机制配置 | 触发条件、资源上限、效果参数，全部表驱动 |

## 11. 诚实边界

- 六系**中文名与原型绑定未确认**，当前用资源前缀 + 原型代号占位；定名后需整体替换。
- 属性基线为相对系数草案，**未经数值技能交叉校验**，正式值由独立数值表承载。
- 专属机制中的实体产出（仆从、领域）**依赖 #1 性能验证结果**，实体上限需压测后回写。
- 新增属性（拾取半径、经验/金币倍率、持续伤害加成）**需与现有 14 属性体系确认兼容**，涉及 `TbAttribute` 扩表与战斗公式影响评估。
- 本文档不含每系专属技能（sf1/sf2/sf3 动画资源已具备但技能配置未设计），属下一版范围。
