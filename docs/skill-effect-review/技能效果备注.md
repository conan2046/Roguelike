## 后续技能设计匹配规则

- 按 skill_1 这样的技能组统一审核。标记“使用”即包含该组全部后缀（如 _f、_h、_s）；类型、元素与备注同样作用于整组。
- 只从下方“已确认使用”选择，按技能类型、元素与备注匹配，引用资源组名和 Skill ID；具体实现从资源详情取 Clip ID 与 ANI 路径。
- 待确认、标记不用或源表已移除的技能组不可自动选用；没有匹配时先说明缺口。旧版片段记录仅用于迁移留档，不代表当前决定。
- 此文件是人工资源审核依据，不是战斗配置；最终绑定必须进入正式 Luban 表并走功能确认流程。

- 飞行朝向支持正式配置、水平镜像、原始方向；后两者指定 f 段最终方向，正式 flipX 同步后不重复翻转。

- 角色可边移动边施法：随身施法用途的 s 段跟随施法者，与发射同时开始，不阻挡移动或等待播完；地面爆炸等落点用途的 s 段留在落点，不按后缀一律跟随。
