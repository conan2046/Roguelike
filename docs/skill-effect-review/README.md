# 技能效果审核工具

手动入口：Unity 菜单 **Roguelike > 技能效果审核 > 打开审核场景**。

不再因打开审核场景、脚本重载或测试恢复场景而自动弹窗。开始 Play 时保存记录并关闭审核工具；正式战斗测试保持正式启动场景，不在收尾自动恢复审核界面。

## 使用方法

1. 在编辑模式查看四格动画，每页四组技能，无需点击 Play。
2. 按 `skill_1` 这样的整组审核。标记“使用”即包含该组 `_f`、`_h`、`_s` 等全部后缀，类型与备注也属于整组。默认“组合播放”连续查看整套效果，可切换“分段查看”检查选中的原始片段，有多个 ANI 动作时可切换动作索引。
3. 对整组选择“待确认 / 使用 / 不用”，技能类型下拉多选，元素下拉单选，备注自由填写。类型、元素与备注均属于整组，切换后缀保持不变。
4. 备注停止输入半秒后自动保存，翻页和关闭时也保存；写入失败会明确显示“未保存”。可手动点击“保存备注”重试。
5. 搜索支持技能组名、技能名称、Skill ID、Clip ID、资源路径、类型、元素和备注。状态筛选按整组判断。“资源详情”中可查技术 ID：`20001` 是 `skill_1` 的技能组 ID，`30002 / 30003 / 30004` 是其 `_f / _h / _s` 动画片段 ID，不代表等级、品质或额外技能。
6. “查看备注文档”定位本目录的 `技能效果备注.md`。重启 Unity 后决定从 `annotations.json` 恢复。

## 后续选用规则

技能类型选项：近战斩击、飞行弹丸、直线射束、扇形喷射、落点爆发、持续区域、环绕旋转、连锁跳跃、治疗恢复、护盾防御、增益强化、控制减益、召唤生成、移动范围。

“移动范围”用于区域本身沿地面持续移动的表现，例如移动龙卷风。与停留在原地的“持续区域”区分；只描述资源适用类型，不自动赋予持续伤害或穿透规则。

元素选项：未选择、物理、火、冰、雷、风、土、毒、光、暗、无属性。未选择表示还未判断，无属性表示审核人明确判断为无元素属性。

旧版手填内容保留在“原填写类型”中，文档也保留独立列。明确的“子弹”与“buff”首次迁移为“飞行弹丸”与“增益强化”；其他无法精确对应的旧文本保持原样，供审核人重新选择。取消全部勾选后不会再次自动填回。

- `annotations.json` 的 `Groups` 是整组审核决定的唯一来源。`Entries` 保留资源身份及旧版片段记录用于迁移留档，不再以其中旧状态判断是否使用。`技能效果备注.md` 同步导出整组清单和资源详情，不要单独修改导出的 Markdown。
- 后续技能设计先读“已确认使用”，按整组类型、元素与备注匹配，引用组名和 Skill ID；具体实现从资源详情取 Clip ID 与资源路径。
- 只允许选择当前正式目录仍存在、且整组明确标记“使用”的资源。选用整组即包含全部后缀，不再要求逐段确认；没有匹配时先说明缺口，不自行选用待确认或不用的组。
- 没有可用匹配时说明缺口，等待审核或另行确定资源；人工审核不等于已经修改战斗绑定。正式功能仍走方案确认、Luban 数据、实现和验收流程。

## 连续组合播放

- 飞行组：随身 `_s` 与 `_f` 同时开始，不等待 `_s` 播完；`_s` 跟随施法者，`_f` 从发射瞬间的位置独立飞行两秒，再接 `_h` 首帧。缺少片段时只播放实际存在的阶段，不生成替代效果。
- 黄色十字表示施法者位置，审核中让它独立走动以检查随身层是否跟随；这是纯编辑器位置示意，不加载角色副本、不修改正式移动速度。随身层跟施法者，不跟弹丸，也不绑定到受术目标。
- 落点组：不按后缀字母猜测下降位置，读取 ANI 的原生帧坐标。当前 `skill_3_h` 自身包含下降与砸中，首次触地帧约在 0.3 秒；此时衔接 `skill_3_s` 的地面爆炸层，两段按各自完整时长结束。触地以画面模块首次跨过共同锚点为审核演示判据，不作为正式碰撞规则。
- 同组所有阶段共用完整流程包围盒与原始像素锚点，保留相对位置和大小；不分别居中、不逐帧适配。飞行起点、轨迹和两秒时长是用户要求的编辑器演示，不替代正式技能速度、碰撞、命中事件与位置配置。
- 左右等变体按正式 ANI 文件名中的完整后缀精确配对，`SourceSuffix` 仅保存末段时不足以判断方向。缺少对应变体时只允许使用公共无方向段，不把左段接到右段。只有单段或未识别后缀时仍可播放原始资源；切换“分段查看”可逐段检查，整组审核决定保持不变。
- 每个卡片显示组合顺序和当前阶段；暂停、速度、缩放与重播本页作用于整条组合时间轴。阶段切换复用已加载的内存帧，不在每轮重播时读盘或创建资源。
- 飞行朝向可选择“正式配置 / 水平镜像 / 原始方向”。后两项保存的是最终朝向，只作用于飞行段；正式配置同步 `flipX` 后也不会二次镜像。旧版“飞行水平翻转”按同步前的正式配置迁移，已有人工决定保留。审核选择不会自行修改 Luban 源表；正式引用同步记录见 [测试技能效果引用更新](test-skill-effect-reference-update-20261027.md)。

## 正式战斗随身层

已按整组审核结果接入独立随身施法层，具体资源、配置字段与验收见 [随身施法效果正式接入](caster-effect-runtime-integration.md)。运行时从 Luban 的 `castClipId` 读取用途，不根据 `_s` 后缀猜测；施法与弹丸同时触发，随身层跟随施法者，落点层继续使用原范围绑定。

## 旧记录迁移

- 版本一逐片段记录自动升级到版本二整组记录，并完整保留原片段分类与备注。升级前副本在本轮 `.local/skill-effect-review/before-whole-group/`，不作为正式配置。
- 同组只有一个明确的使用决定、其他片段待确认时，将明确决定应用到整组；类型取已有选择合集，单一元素与备注保持原样，多份备注按原片段来源合并。
- 若旧片段同时存在“使用”和“不用”，整组初始为待确认并提示冲突，不替用户取舍。若旧片段元素不同，整组元素初始留空，原值继续留档。

## 工具边界与参考审查

- 本工具属于编辑器资源测试工具；不新增正式玩法、技能类型枚举、战斗数值或默认业务配置，因此不新增 Luban 表。目录与资源关系来自当前 `TbSkill → TbVisualSet → TbAnimationClip → TbResource`，ANI 时钟、过滤方式与场景 Shader 来自 `TbCombatPresentation`。
- 审查当前 `SkillPrefabPreview`、`CombatCylinderPipeline`、`AniFrameLayout`、`AniMeshFactory` 后，采用共享 ANI 解析、翻转语义与内存资源所有权；采用整组审核、分段查看、全动作稳定包围盒和四组分页。拒绝生成或持久化任何预览纹理、网格、材质。
- 本轮指定的 Tower 参考路径不可访问，无法检查同类效果审核工具；依据本工程现有分层实现，并核对 `CombatEntityVisuals` 的飞行、命中与范围表现入口。工具入口、播放、文档保存均在 Editor 程序集中，无网络、账号、业务异步加载或对象池；只为当前页四组加载所需阶段。翻页、换组、关闭场景或窗口、Play 切换和域重载释放全部阶段的独占内存。单段装载失败显示在卡片，文档损坏拒绝覆盖，保存失败保留未保存提示。
- 新场景只保存一个相机。纹理从正式 PNG 读取，网格、材质和场景效果对象只在内存中建立并设置 `HideAndDontSave`；保存场景不会写入这些对象或外观引用。窗口卡片直接使用共享帧模块绘制，不生成缩略图或资源副本。
- 自动重复播放、速度、四格布局、统一取景、重绘限频、相机取景、界面文案及审核分类选项均为纯编辑器测试参数，不流入正式运行配置。类型按名称保存，不依赖界面选项顺序；它们不是正式技能机制或元素配置枚举。组合展示验证资源与演示衔接；真实战斗的技能时序、速度、伤害与碰撞仍须在正式入口另行验收。
- 有未保存的其他场景时审核场景以叠加方式打开并保留它们；无未保存场景时单独打开审核场景。工具不加入 Build Settings、不修改现有 Scene/Prefab、不构建 Win64。

## 验收标准

- 四格自动播放、翻页与末页空位、片段与动作切换、暂停/速度/缩放可用。
- 飞行阶段恰好演示两秒再接命中首帧；落点在原生触地帧接地面层，同一原点与共同取景保持稳定。重复采样不推进，整轮重播不丢阶段，热路径不重复创建纹理。
- 随身施法层与弹丸在同一时刻开始，移动时跟随施法者而非弹丸；地面爆炸层仍固定在落点，不能误用随身绑定。
- 中文与多行整组备注保存重载不丢失，切换后缀不改变整组决定，Markdown 分隔符安全转义并保留全部后缀技术 ID。
- 只有整组标记“使用”且源资源仍有效的技能组进入匹配清单；新组默认待确认，失效组保留备注但不进入匹配，旧记录迁移与冲突留档可追溯。
- 原始 ANI/PNG 全片段装载检查通过，切换与关闭无内存对象残留，场景不保存外观对象。
- 自动化与编辑器交互验证完成后交用户人工确认；不把测试通过描述为用户已认可资源表现。
