## 诊断可靠性

- 早期跨帧参考本身不稳定，且切换血条DisableRendering可能迁移同archetype的数字。夹具先将血条与其他渲染隔离，保留原路径重复渲染控制。
- 诊断串行化剔除后，六场景参考重复差异均为0；GPU混合原型仍有上述30像素差异。串行化只用于像素门禁，finally恢复原JobWorkerCount，不作为性能优化或容量测试设置。
- 剩余差异在被保留原提交的重叠条上，不在实例化玩家条的矩形内。它支持“减少命令总数仍可能改变同深度排序结果”这一推断；没有声称取得单事件Frame Debugger或GPU归因证据。
- 主要冻结证据：`.local/performance-20261025/20261025-054101/`，含RGBA原图、对照图、重复参考图、几何CSV及`bar-pixel-comparison.json`。放大差异图在`.local/performance-20261025/healthbar-repair/pixel-difference-analysis.png`。
