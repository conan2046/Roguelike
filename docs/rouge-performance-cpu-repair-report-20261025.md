## 实现与诊断

1. P0冻结105项原有已跟踪脏文件和6份相关代码；建立合法48怪、8种普通怪、同种子/输入的逐Tick轨迹。
2. P0短诊断累计26717497次接触，其中26652708次没有位置进展、25670168次连续重复接触。主因包含边界夹取的大坐标加减与单法线投影的有限精度循环。
3. P1新增会话独占NativeList状态缓冲，每Tick一次从ECS采集、连续读写、一次提交；32处内部单位访问改用槽位数组。缓冲随实际槽数增长，Job同步后扩容，重开覆盖，Dispose释放；外部ECS修改仍在下一Tick重新采集。
4. P2最终保留原夹取、最早命中、稳定槽序、ULP退让和滑动公式。仅在位置位模式不变的区间，通过Brent倍增检查点检测夹取余量的位级循环。网格/其他单位在函数内不变，重复状态会永远重复且位置不变，提前终止与旧循环耗尽上界的终点一致；没有新容差或更小迭代上限。
5. 早期半平面投影实验没有进入最终实现：它需要改变切向数值处理；已移出Assets，仅保留.local诊断历史。最终采用更窄的精确循环消除，保证轨迹输出一致。

500档短诊断：P0模拟P95 135.21ms；P1 72.71ms；精确循环修复首版1.91ms。该系列含CPU Profiler开销，正式结论以上方完整六组为准。最终实现额外使用位模式比较，区别正负零；完整复测包含此版本。
