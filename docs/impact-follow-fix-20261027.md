# 命中特效跟随目标修复

用户要求受击动画挂在被命中的目标上，在播放期间随目标移动。当前 CombatTickJob 在接触时写入 CombatImpactEvent.Position，CombatEntityVisuals 随后只采样动画帧，没有同步位置，是特效留在原地的原因。

采用既有 ECS 数据和表现分工：接触事件补充真实 TargetSlot，与已有 TargetLifetime 共同标识目标；表现池保存二者，在每次 Synchronize 中消费同一份权威单位只读快照，以目标 Position + HitEffectOffset + 技能命中特效偏移更新位置。查询按槽 O(1)，不扫描单位、不创建每目标 GameObject、不使用 Unity Transform 父子绑定。

既有 TbCharacter/TbMonster 受击挂点、TbSkill 的 ImpactVisualOffset/Scale 和 TbCombatRender 技能片段层级继续为唯一表现参数来源，无需新增或修改源表、表结构和 Luban 生成物。事件槽位和生命周期是运行时身份元数据，不是策划常量或默认配置。仅 Impact 跟随目标，TargetArea 地面落点和已有跟随拥有者语义均不改变。

目标存活且生命周期一致时跟随；死亡、目标不可用或槽位复用时停止跟随，在最后的有效位置播完本次 ANI，保留致死命中的反馈但不会转移到新怪物。动画结束、重开、退出沿既有池化和销毁链清理；无新增异步加载、资源所有权、UI 绑定或存档改动，沿用既有异常清场。Tower Battle 参考目录当前不可访问，依据本工程的 ECS 与共享资源结构修复，不引入其旧业务链。

验收：真实弹丸产生的命中特效在同 Tick 目标位移时同步位移；保持挂点与技能偏移、缩放、层级；死亡和复用后不跳位，播完回池；重开无旧目标残留；地面范围片段不跟随目标；检查并发命中、真实入局画面与退出。修改前保留本轮涉及的全部已有脏文件，不修改场景、Prefab 或数据表，不提交、推送或构建。
